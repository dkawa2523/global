## 次に進める作業

優先するのは段階7です。前提となるDC参照比較の条件整備と、独立実験の観測量の選定から進めます。
開発の物理的な目的・順序・完了条件は[Theory第16節](THEORY.md#future-development)に示します。

DC例では、元入力の全初期種密度を確認し、初期電子密度の差を解消します。
独立に生成した電子係数を用いて、初期状態・反応機構・比較時刻を揃え、立上りと回路応答を比較します。
独立実験との比較は、次の手順で準備します。

1. 観測量と観測領域を決め、局所値・線積分とzone平均の対応を定義する。
2. 体積、壁面積、気体温度、吸収電力、測定誤差を確定する。
3. 校正に使う条件と、評価に残すpressure／power条件を分ける。
4. 許容差と保存間隔の収束を確認し、独立した評価条件で比較する。
5. 測定または根拠のある入力分布から不確かさを伝播する。任意の感度幅を信頼区間にしない。

その後、電子係数の組成依存と低温afterglow・壁近似の適用範囲を優先して評価します。
気体熱・表面・蓄積、RF結合、全収支解析は対象用途の検証で必要になったものから進めます。
空間方向への拡張は、長さ・断面積・境界条件と分割収束を含む別の設計課題として扱います。

## 残る課題と拡張候補

| 項目 | 現状 | 次に必要なこと |
|---|---|---|
| 電子係数の組成依存 | 外部表の生成条件に依存。近似two-term表は初期中性組成比に固定 | 独立Boltzmann計算との比較、更新・補間の必要性の評価 |
| DC保存参照の初期条件 | 同梱caseは2種のイオンseedからnₑ=2×10¹² m⁻³。参照条件欄の1×10¹² m⁻³との差をTheoryへ明記 | 元入力の全初期種密度を確定し、初期状態・係数生成を揃えた独立比較を追加 |
| RF・表面・気体energy等 | 機能は接続済み、experimental分類 | 装置条件を揃えた独立比較 |
| イベント累積数 | 保存点からの区間別台形積分 | 用途ごとの保存間隔収束、必要なら積分方式の再検討 |
| 全収支の可視化 | 化学反応図のみ。入口・排気・輸送・壁電荷・closureは含めない | 物理的なdomainと単位を定義し、化学反応と区別して表示 |
| 擬似1次元 | 方向付きedgeでzoneを接続する区画モデル | 長さ・断面積・移流拡散・境界条件・分割収束の明示設計 |
| 範囲指定の名称 | 電子・電源CSVはhold、単一速度表はclip | 意味を変えずに統一する場合の互換性設計 |
| 表面反応係数の名称 | `A_m2_s_inv` は実装でsite密度の2乗へ掛けるm²/sの係数。現行マニュアルに次元を明記 | 互換性を設計して次元が伝わる変数名へ整理 |
| 表面反応熱の入力範囲 | 表面YAMLのgas_heating_eVは符号付き、反応CSVは非負。形式間の差をマニュアルに明記 | 反応familyごとの対応範囲を決め、YAMLとCSVの値域を統一 |
| 電源固有probe | 初期評価で利用可能でもoff時に未定義になる量がある | 要求量の全運転区間での利用可能性を事前に判定する設計 |
| 低温afterglow | Ar例の終端電子温度は300 K相当より低く、冷イオンBohm近似の前提が弱い | イオン温度・分布・壁closureの適用条件を独立に確認 |
| 近似EEDFの代理損失 | 分布生成の0.03 eV固定弾性損失は粒子solverの温度差依存式と異なる | 独立Boltzmann計算とenergy交換の整合を評価 |

擬似1次元は拡張候補であり、現在のedgeが流体・拡散を解くと説明しません。
これらの機能拡張を文書整理だけで実装済みにしたり、装置検証済みにしたりしません。
