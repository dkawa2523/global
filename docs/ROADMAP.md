# 計画と残る課題

公開宣言から計算・保存・再利用までの基盤を実装し、解析解、保存参照、限定した実測比較で評価してきました。
次は、利用予定の装置で必要な観測量と許容差を定め、既存モデルの近似をどこまで使えるか判断します。
現行の入出力は[マニュアル](index.md)、根拠のある結果と適用範囲は[Theory](THEORY.md#discussion)、
実行記録は[開発・保守](DEVELOPMENT.md#change-record)にあります。

<a id="validation-plan"></a>

## 対象装置で使える条件を確かめる

まず観測量を一つ選び、用途に必要な許容差を事前に決めます。停止後の寿命であれば、測定時系列と観測領域、
圧力・温度・容器形状・壁条件、数値側で比較する時間帯をそろえます。DC運転であれば、同じ時刻・基準点での電圧、
電流と電子密度を候補にします。局所値、場で重み付けした平均、体積平均の対応も定義します。

次に校正に使っていない運転条件で比較します。ODE許容差と保存間隔を別々に確かめ、測定誤差と根拠のある入力の幅を示します。
条件・比較時刻・観測の定義と、差および不確かさを再現でき、用途の許容範囲と照合できることを完了条件とします。
独立した測定時系列と、装置・境界条件の記録が必要です。

## 比較結果から選ぶ拡張

差が許容範囲を超えた場合は、影響が大きい入力や収支項を絞ります。
通電中の密度・回路量には電子係数、電力分配、壁損失を、後期残光の寿命には境界と熱の扱いを先に調べます。
表は着手候補と、その変更を受け入れるための確認方法です。

| 候補 | 着手の判断と完了の根拠 |
|---|---|
| 組成・温度依存の電子係数 | 独立の電子計算で組成・温度を振り、速度係数、輸送係数、観測波形への影響を確認します。差が用途に効く場合は表の軸や更新方法を設計し、生成条件とエネルギー収支の整合を示します。 |
| 低温の停止後応答と壁 | 必要な時間帯の密度、温度または粒子束を測定と比較します。開口を含む境界、幾何と熱条件を揃えた上で、輸送・壁近似の使用範囲を決めます。 |
| 気体熱、表面、蓄積 | 既存の熱容量、輸送、表面サイト、反応収率で対象量を説明できるか確認します。蓄積を収支に反作用させる場合は、寄与と依存を定義し、エネルギー・元素・サイト収支と観測量の両方を照合します。 |
| RF・CCP・ICP、双方向回路、励起準位 | 現行の経験式は、校正に使っていない条件で吸収電力、電圧、電流、自己バイアス等を比較します。回路への反作用や準位緩和が収支や観測量を左右する場合に、必要な結合と時間尺度を定義します。 |
| 装置全体の収支と累積量 | 入口、排気、移送、壁、反応を共通の対象範囲と単位で追跡できるか確認します。累積量の要求精度と保存間隔の収束から、追加の系列や積算方法の必要性を判断します。 |
| 空間方向 | 区画平均で失われる勾配が関心量に効く場合、長さ、断面積、境界条件を定義します。既知の移流拡散問題との比較と分割収束を確認できる形で設計します。 |

## 公開経路で残る整合課題

系列名に入るIDについて、入力とHDF5レイアウトの制約を計算開始前に整合させる必要があります。
計算・保存に使えるIDは最後まで扱え、扱えないIDは `validate` が対象を特定できることを完了条件とします。
