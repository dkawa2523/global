## 次に進める作業

優先するのは段階7です。見た目の一致を目指す前に、比較する物理量を揃えます。

1. 観測量と観測領域を決め、局所値・線積分とzone平均の対応を定義する。
2. 体積、壁面積、気体温度、吸収電力、測定誤差を確定する。
3. 校正に使う条件と、評価に残すpressure／power条件を分ける。
4. 許容差と保存間隔の収束を確認し、独立した評価条件で比較する。
5. 測定または根拠のある入力分布から不確かさを伝播する。任意の感度幅を信頼区間にしない。

## 残る課題と拡張候補

| 項目 | 現状 | 次に必要なこと |
|---|---|---|
| 電子係数の組成依存 | 外部表の生成条件に依存。近似two-term表は初期中性組成比に固定 | 独立Boltzmann計算との比較、更新・補間の必要性の評価 |
| RF・表面・気体energy等 | 機能は接続済み、experimental分類 | 装置条件を揃えた独立比較 |
| イベント累積数 | 保存点からの区間別台形積分 | 用途ごとの保存間隔収束、必要なら積分方式の再検討 |
| 全収支の可視化 | 化学反応図のみ。入口・排気・輸送・壁電荷・closureは含めない | 物理的なdomainと単位を定義し、化学反応と区別して表示 |
| 擬似1次元 | 方向付きedgeでzoneを接続する区画モデル | 長さ・断面積・移流拡散・境界条件・分割収束の明示設計 |
| 範囲指定の名称 | 電子・電源CSVはhold、単一速度表はclip | 意味を変えずに統一する場合の互換性設計 |
| 電源固有probe | 初期評価で利用可能でもoff時に未定義になる量がある | 要求量の全運転区間での利用可能性を事前に判定する設計 |

擬似1次元は拡張候補であり、現在のedgeが流体・拡散を解くと説明しません。
これらの機能拡張を文書整理だけで実装済みにしたり、装置検証済みにしたりしません。
