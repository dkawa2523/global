# Robustness Benchmarks

## Purpose

`tools/external_benchmarks/robustness_sweep.py` checks whether the code breaks
when pressure, electrical drive, and chemistry are changed away from the
single ZDPlaskin parity point.

It deliberately separates two meanings of "benchmark":

- external-reference checks: strict pass/fail against saved external results;
- stress checks: solver health, finite positive densities, and closure range
  checks without claiming accuracy.

## Current Coverage

External references:

- ZDPlaskin `example2`: same-footing final-state comparison for Ar DC-resistor
  chemistry/circuit.
- CRANE TwoReactionArgon: scalar ODE chemistry comparison with prescribed rate
  constants.
- PyGMol Ar: executable global-model sanity check for the pure-Ar LXCat case.
  This is order/trend validation, not strict same-physics parity.

Stress cases:

- ZDPlaskin-derived Ar case at 50 torr and 200 torr.
- ZDPlaskin-derived Ar case at 500 V and 1500 V source voltage.
- Pure-Ar LXCat ICP baseline.
- Pure-Ar LXCat ICP pressure perturbation at 16 Pa.
- Pure-Ar RF-envelope calibration case.
- Ar/CF4/O2 smoke chemistry case.

Run:

```powershell
py tools\external_benchmarks\robustness_sweep.py
```

## Current Result

All external-reference and stress cases run successfully with positive finite
electron densities.

The ZDPlaskin pressure/voltage stress cases now use the wide diagnostic table:

- `examples/chemistry_zdplaskin_example2/tables/zdplaskin_example2_wide_eovern_rates.h5`
- E/N range: `0.5 - 250 Td`
- source: imported ZDPlaskin `example2/bolsigdb.dat` cross sections
- generator: `tools/external_benchmarks/build_zdplaskin_rate_table.py`

This removes the immediate rate-table range failure for the 50 torr and 1500 V
stress cases. They remain stress checks, not accuracy benchmarks, because the
wide table is generated by this repository internal two-term-like solver and
there is no external reference output at those conditions.

## Interpretation

The code no longer collapses immediately when moved away from the ZDPlaskin
base point. It runs through pressure, electrical-backend, and chemistry
changes.

The dashboard outputs make that broader message easier to read:

- `robustness_stress_overview.png` shows whether final/peak electron density,
  mean electron energy, absorbed power, and reduced field remain finite and
  bounded across the added stress cases.
- `robustness_rate_table_coverage.png` focuses on the ZDPlaskin-derived
  pressure/voltage stress family and shows whether the observed E/N range stays
  inside the widened diagnostic table.
- `robustness_applicability_report.md` gives a short paper-style interpretation
  so these added cases can be cited as applicability evidence without confusing
  them with strict validation.

The part that is still weak is benchmark authority outside the existing
reference points. The next useful improvement is not more tuning of one case;
it is adding BOLSIG+/external-code reference outputs for the wider pressure and
voltage regimes.
